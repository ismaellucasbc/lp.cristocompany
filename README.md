# Cristo Company — site

Site estático (HTML, CSS e JS puros), sem etapa de build. Publicado na Vercel a partir deste repositório: cada alteração enviada para a branch `main` vai ao ar automaticamente.

## Onde editar

- `index.html` — textos e estrutura das seções.
- `styles.css` — cores e fontes (variáveis no topo do arquivo).
- `script.js` — links (`LINKS`) e lista de versículos do dia (`VERSES`).

## Pendências marcadas com [COLCHETES]

Logo oficial, foto do hero, capas e links dos vídeos, texto completo do devocional, link da loja, link do grupo da comunidade, contato, políticas e CNPJ.
